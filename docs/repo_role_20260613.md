# Repo Role: projectscanner

Last synchronized: 2026-07-03

Status: active toolbelt repository.

## What this project is

ProjectScanner is repository scanning and inventory intelligence tooling in the software repository analysis domain.

## Why it exists

It scans, inventories, and reports on local and GitHub repositories so downstream Dream.OS/DreamVault workflows can make cleanup, consolidation, promotion, and review decisions from evidence instead of guesswork.

## Role

- Repository inventory generation.
- Local and GitHub scan target support.
- Machine-readable scanner reports and context exports.
- Documentation-gap and cleanup signal export.
- Artifact-standard checks.

Unknown:

- Any durable governance role beyond artifact generation. Current docs assign durable governance and decision records to DreamVault.

## Boundary

ProjectScanner should not own Dream.OS runtime state. DreamVault remains the documented portfolio governance and decision-record layer. ProjectScanner emits evidence and reports.

## Output style

Reports should be machine-readable where possible and written into the caller's chosen report directory. The exact external DreamVault path is environment-specific and Unknown from this repository alone.
