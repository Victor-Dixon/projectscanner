# Repo Role: projectscanner

Status: active toolbelt repo.

This repository is not a Dream.OS variant. Its job is to scan, classify, and report on local/project repositories so DreamVault can make safe consolidation decisions from evidence instead of guesswork.

## Role

- Repo inventory generation
- Duplicate/stale/salvage classification
- Promotion manifest support
- Cleanup reports before archive/delete decisions

## Boundary

projectscanner should not own Dream.OS runtime state. DreamVault remains the operational control and task SSOT. projectscanner emits evidence and reports.

## Required output style

Reports should be machine-readable where possible and written into the caller's report directory, usually:

`DreamVault/data/reports/github_consolidation/`
