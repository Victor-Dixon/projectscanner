### 🚀 **How to Use:**

#### **🖥️ Launch Options:**
1. **main.py:** `python main.py` - Direct GUI launch
2. **launch.py:** `python launch.py gui` - Launcher script
3. **Token Wizard:** `python launch.py token-wizard` - Token setup

#### **🔐 Token Wizard Flow:**
1. **Welcome** → Click "Next"
2. **Generate Token** → Open GitHub, click "I've Generated My Token"
3. **Enter Token** → Paste token and username (real-time validation)
4. **Verify Token** → Click "Test Token" to verify
5. **Complete** → Click "Finish" to save configuration
